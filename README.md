## نبذة عن المشروع | Project Overview

مشروع تعليمي تطبيقي مخصص لطلاب الفئة الثالثة في مقرر هندسة البرمجيات بجامعة ماري الخاصة، يهدف إلى تطوير نظام لإدارة عيادة الأسنان، من خلال تطبيق مبادئ هندسة البرمجيات عمليًا، بدءًا من تحليل فكرة النظام وتحديد متطلباته، وصولًا إلى التصميم والتنفيذ والاختبار والتحسين التدريجي.

This repository contains an educational Dental Clinic Management System developed by Software Engineering students at Mary Private University, Practical Section 03.

The project demonstrates software engineering concepts through iterative development, starting with a Python console prototype.

## الأهداف التعليمية | Learning Objectives

- فهم مفهوم النظام وأصحاب المصلحة (Stakeholders).
- تحليل وظائف النظام ومتطلباته (Features & Requirements).
- تنظيم المشروع وملفاته وتوثيقه.
- تحويل الوظائف إلى دوال Python.
- اختبار وظائف النظام وتحليل المشكلات.
- تطبيق مبادئ التطوير التدريجي (Iterative Development).
- استخدام Git وGitHub لتوثيق مراحل العمل.

## الجلسة العملية الأولى | Practical Session 01

**من فكرة النظام إلى أول Prototype منظم باستخدام Python**

### Current Features — v0.1

1. **Add Patient** — إضافة مريض جديد.
2. **View Patients** — عرض قائمة المرضى.
3. **Add Appointment** — حجز موعد أولي.
4. **View Appointments** — عرض المواعيد المسجلة.
5. **Exit** — الخروج من التطبيق.

### Technologies

- Python 3
- Command-Line Interface (CLI)
- Python Lists & Functions
- Git & GitHub

### Project Structure

- `main.py` — الشيفرة البرمجية للنظام.
- `README.md` — توثيق المشروع.
- `notes.txt` — الملاحظات والمشكلات والأفكار المستقبلية.

### How to Run

1. Install Python 3.
2. Clone or download the repository.
3. Open the project directory.
4. Run `python main.py`.
